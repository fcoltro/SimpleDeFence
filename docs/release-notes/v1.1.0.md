# SimpleDeFence 1.1.0

New: "Stop it trying" for blocked apps that keep retrying, a much quieter Blocked list, and fixes
from a full code review.

## Install

Download `SimpleDeFence_x64.msi` below and run it, or let an earlier version offer you the update
in-app. Your rules and settings are kept.

Windows 10 version 2004 (build 19041) or newer, or Windows 11, 64-bit.

Verify the download if you like: its SHA-256 is in `SHA256SUMS.txt` below and in
[`updates/update.json`](https://github.com/fcoltro/SimpleDeFence/blob/main/updates/update.json),
and the in-app updater checks it for you before running anything.

```
Get-FileHash .\SimpleDeFence_x64.msi -Algorithm SHA256
```

## New

- **Stop it trying.** Blocked apps from big suites, such as Adobe Creative Cloud and Autodesk,
  retry in the background for ever. Right-click one on the Connections page and choose
  **Stop it trying**: SimpleDeFence lists the services, scheduled tasks and startup entries signed
  by the same company. Untick what you don't want and it is switched off and won't start again.
  Licence checkers are marked, Windows' own parts are never listed, and **Switch all back on**
  restores everything SimpleDeFence switched off.
- **Repeated blocks are merged.** An app that keeps retrying shows as one row with
  "N attempts", instead of flooding the Blocked list.
- **Less work for Windows.** Allowed connections are now only logged by Windows while Learning
  mode is on, which is the only time they are read.
- **Connection log:** an app that keeps retrying writes one line a minute, with a new
  "Attempts in last 5 min" column.
- **Clean up** now lists the programs whose rules it will remove before you confirm.
- A project website: <https://fcoltro.github.io/SimpleDeFence/>.

## Fixed

- Timed rules and Learning's time limit no longer gain or lose an hour when daylight saving
  time changes.
- After a failed switch out of Learning, open windows now show the rules Learning added.
- Trusted publishers: programs in folders that a normal user can change are checked again on
  every start instead of being remembered.
- The updater accepts downloads only from this project's GitHub releases.
- The control pipe refuses internal timer messages from outside the service.

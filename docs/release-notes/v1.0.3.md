# SimpleDeFence 1.0.3

New features: notifications, temporary rules, a time limit for Learning, trusted publishers,
custom rules, public network lockdown, your own IP blocklist, rule clean-up and a command line.

## Install

Download `SimpleDeFence_x64.msi` below and run it, or let an earlier version offer you the update
in-app. Your rules and settings are kept.

Windows 10 version 2004 (build 19041) or newer, or Windows 11, 64-bit.

Verify the download if you like: its SHA-256 is in `SHA256SUMS.txt` below and in
[`updates/update.json`](https://github.com/fcoltro/SimpleDeFence/blob/main/updates/update.json),
and the in-app updater checks it for you before running anything.

```
Get-FileHash .\SimpleDeFence_x64.msi -Algorithm SHA256
```

## New

- **Notifications.** A tray notification the first time an app is blocked from connecting, or
  starts accepting incoming connections. Click it to open that app on the Connections page. Both
  can be switched off in Settings > General.
- **Temporary rules.** Allowing an app asks how long: 5 minutes to 24 hours, until restart, or
  always. The rule removes itself, and the Rules page shows when it ends.
- **Learning with a time limit.** Learning switches back to Normal after 10, 30 or 60 minutes,
  even with the window closed, and then offers to show the rules it added.
- **Trusted publishers.** Allow every program signed by one vendor, so an app keeps working after
  updates that install to a new folder. Only signatures Windows verifies count, and Windows'
  own programs are never allowed this way.
- **Custom rules.** A rule can be a list of allow and block entries by direction, protocol,
  address and port. Rule lists from the app database, which were read-only, can now be edited.
- **Lock down on public networks.** On café or hotel Wi-Fi, "Allow local network", file and
  printer sharing, network discovery, ping and remote access are turned off until you are back on
  a private network. Off by default; in Settings > Protection.
- **Blocked addresses.** Your own list of IP addresses and networks that no program can reach, in
  Settings > Blocklists.
- **Clean up.** One button on the Rules page removes the rules for programs that are no longer
  installed.
- **Ctrl+Alt+B** switches to Block all and back.
- **A command line** for scripts: `/mode`, `/mode learning /minutes N` and `/allow <path>`.
- **14 more known apps**, including Discord, Spotify, Zoom, Slack, Visual Studio Code, Brave,
  Opera, OneDrive, Microsoft Teams, Dropbox, Epic Games, Battle.net, Signal and Telegram. Skype
  and Windows Sidebar were removed.

# SimpleDeFence 1.2.0

New: folder rules with wildcards, a "Data used" list per app, and a Rules page that no longer
keeps refreshing. "Stop it trying" is removed.

## Install

Download `SimpleDeFence_x64.msi` below and run it. Your rules and settings are kept.

Windows 10 version 2004 (build 19041) or newer, or Windows 11, 64-bit.

Verify the download if you like: its SHA-256 is in `SHA256SUMS.txt` below.

```
Get-FileHash .\SimpleDeFence_x64.msi -Algorithm SHA256
```

## New

- **Folder rules.** On the Rules page, **Add > Folder** opens a window where you name the rule,
  enter one or more folders or patterns (one per line, or use **Browse**), and choose Allow or
  Block. `*` matches any name inside one folder, `**` any number of folders, and `?` one
  character, for example `C:\Tools\**` or `C:\Games\*\game.exe`. Machine-wide variables such as
  `%ProgramFiles%` work. The rule covers the programs there now and any added later, and the window
  shows how many programs match as you type. It warns you when normal users can write to the
  folder. A rule for one program always wins over a folder rule, and the most specific folder rule
  wins over a broader one.
- **Data used.** A new section on the Connections page lists how much each app has sent and
  received since the service started, with the current speed. The filter box filters it too.

## Fixed

- **The Rules page kept refreshing**, so rules could not be selected and Remove and Clean up did
  not work. It now stays still and keeps your selection, and long rule lists open faster.
- **Add** on the Rules page failed with "Unspecified error (0x80004005)". The file and folder
  pickers now work while the app runs as administrator. Import and export in Settings use the same
  fix.
- **Settings shook at the bottom.** Scrolling to the end of the Settings page made it jump up and
  down, and the last row of About could not be reached. It now scrolls smoothly to the end.
- When Learning mode's time limit ends, the firewall goes back to the mode you were in, not always
  to Normal.
- If another program holds the control channel's name, the service keeps trying to open it instead
  of staying unreachable until a restart.
- Uninstalling now undoes "Reduce Windows telemetry".
- From the next update on, upgrading keeps the firewall running and works even while the settings
  are locked with a password.

## Removed

- **Stop it trying** did not work well, so it is gone. Everything it switched off (services,
  scheduled tasks and startup entries) is switched back on after this update. Your own startup
  apps come back within 10 minutes of signing in. **Mute this app** stays.

# SimpleDeFence 1.0.1

Two interface fixes, both reported against 1.0. No change to filtering, rules or the service.

## Install

Download `SimpleDeFence_x64.msi` below and run it, or let 1.0 offer you the update in-app.

Windows 10 version 2004 (build 19041) or newer, or Windows 11, 64-bit.

Verify the download if you like — the SHA-256 is published in
[`updates/update.json`](https://github.com/fcoltro/SimpleDeFence/blob/main/updates/update.json),
and the in-app updater checks it for you before running anything.

```
Get-FileHash .\SimpleDeFence_x64.msi -Algorithm SHA256
```

## Fixed

**Rows now highlight under the pointer.** They never had, on any release. A list whose items are
not selectable and not clickable is treated by Windows as display-only, and its rows are never put
into the pointer-over state at all — so the highlight the Connections screen had been carrying
since v0.1.1 was unreachable code that had never once run. The giveaway was that hovering a row
would show its executable path in a tooltip while showing no highlight whatsoever: the pointer was
arriving, the row just was not something that could be hovered. The rows are interactive now, and
the highlight is also stronger, which matters on a screen where rows already carry a colour to say
whether traffic stayed on the local network.

**Rules entries for uninstalled applications are struck through.** A rule whose executable no
longer exists on disk — because the application was uninstalled after the rule was created — now
shows its name struck through in red, with a tooltip saying why. Previously it was
indistinguishable from a rule that was still doing something, so leftover entries accumulated with
nothing to mark them.

## Upgrading

Installed 1.0 clients are offered this release in-app. Your configuration, rules and password carry
over; no reinstall or reconfiguration is needed.

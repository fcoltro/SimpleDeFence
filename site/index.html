A firewall that blocks every app you have not allowed

SimpleDeFence is free and open source. It sits in the notification area, stops unknown programs from reaching the network, and lets you allow the ones you trust with one click. No kernel driver, no account, no data collected.

Download for Windows View the source

Windows 10 (2004 or newer) and Windows 11, 64-bit. GPLv3.

What it does

Blocked by default

Normal mode allows only the programs you chose. Block all, Allow outgoing, Learning and Disabled are one click away in the tray.

Known apps built in

A database of common programs lets you allow them without hunting for executables by hand.

Live connections

See what is connected, listening and blocked. Right-click a row to allow the app, copy its address or open its folder.

Stop it trying

Blocked suites like Adobe Creative Cloud or Autodesk retry for ever. Switch off their background services, tasks and startup entries in one dialog.

Temporary rules

Allow or block an app for 5 minutes up to 24 hours, or until the next restart. The rule removes itself.

Trusted publishers

Allow every program signed by one vendor, so apps keep working through updates. Only signatures Windows verifies count.

Public network lockdown

On café or hotel Wi-Fi, sharing, discovery and remote access are switched off, and come back on your home network.

Password lock

Lock the settings so nothing running as you can change them without the password.

Blocklists

Hosts-file blocklists and your own list of blocked addresses that no program can reach.

Sixteen languages

Including Arabic and Farsi with right-to-left layout.

Download

Get the installer from the latest release on GitHub and run it. It is a single self-contained MSI of about 55 MB: no .NET runtime to install first and no kernel driver. It asks for administrator rights, because programming the Windows Filtering Platform needs them.

Updates are offered inside the app and checked against a SHA-256 published in the repository before anything runs. Each release also lists its checksums in SHA256SUMS.txt.

You can also install it with winget once it is listed: winget install fcoltro.SimpleDeFence.

Free code signing for Windows releases is provided by SignPath.io, certificate by SignPath Foundation. See the code signing policy.

Privacy

SimpleDeFence collects no personal data and has no telemetry. It has no account and sends nothing about you or your computer anywhere.

It goes online only for these:

  • The update check: it reads update.json from this project on GitHub, and downloads new app, database or hosts-file updates from GitHub when you accept them. It can be switched off in Settings.
  • "Look up addresses", only when you click it: the addresses shown go to your DNS server and to rdap.org to find their names and owners.

Connection logs, if you switch them on, stay on your computer. GitHub hosts this website and the downloads; see GitHub's privacy statement for what it records.
